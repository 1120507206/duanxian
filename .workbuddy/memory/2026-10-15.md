### 根因（重要，后续同类问题可复用）
- **侧边栏闪现**：`/` 指向 `Landing.vue`（无侧边栏营销页），`/app` 又 redirect 到 `/ztlive` 而非 `/home`；且路由全懒加载 + `App.vue` 用 `route.name` 判断布局，首帧异步路由未解析时 AppLayout 先渲染 → 闪侧边栏后跳走。
- **默认黑色**：`index.html` 硬编码 `<html class="dark">`；`main.css` 只有一套深色令牌，无浅色、无切换状态。
- **主页不美观**：`Home.vue` 样式大量裸 hex，无法跟随主题。

### 最终实现
- `router/index.js`：`/` → `redirect:'/home'`；`/app` → `redirect:'/home'`；营销页挪到 `/landing`（`name:'landing'` 保留）。
- `App.vue`：`await router.isReady()` 门控首帧，ready 前只渲染同色占位 `.app-boot`，不挂 AppLayout → 消除闪现。
- `assets/main.css`：**双套令牌** —— `:root` 为浅色默认，`html.dark` 覆盖深色；Element Plus 覆盖改走变量；body 用变量。
- `index.html`：`<head>` 内**同步内联脚本**读 `duanxian:themeMode` 提前打 `<html>.dark`（默认 light），消除 FOUC；清除写死的 `dark` / `bg-dark-bg`。
- 新增 `src/stores/theme.js`：Pinia，mode 默认 `light`，`setMode/toggle/sync`，读写 `duanxian:themeMode`，同步 `html.dark` + color-scheme。
- `AppLayout.vue`：新增 56px topbar 承载**右上角主题切换按钮**；样式改走令牌。
- `Home.vue`：去硬编码 + 标题区/index-strip 重做/统计卡色条/卡片质感；ECharts 改 `chartTheme()`（深色 `'dark'`、浅色 `undefined`）+ `watch(isDark)` 重建。
- **浅色回归修复（QA 发现）**：Lianban/Longhu/Zijin/Zixuan/Fupan/Jingjia 六个页面的 `<style>` 仍写死深色中性色（`#e8edf5` 等），浅色下白字白底不可读 → 全部换 `var(--color-*)`；同时 Fupan/Zijin 的 ECharts 也改为跟随主题。

### 教训（重要，下次避免）
- **Grep 正则写错会给出假阴性**：我先用 `"rgba(30, ?58, ?95"`（`?` 只作用于前一字符，且 `0.6` 前无空格）扫描，误报"无残留"，实际 `rgba(30,58,95,0.6)` 仍在。扫 hex/rgba 残留时应**宽松匹配**（如 `rgba(30`）并人工确认，或直接 `sed -n` 看上下文。
- QA 的静态 CSS 级联推断很有效，但**没有真实浏览器渲染**；本项目仍无自动化测试，验证依赖 Grep + build。
