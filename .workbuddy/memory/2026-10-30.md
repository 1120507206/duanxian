- 后端：`cd backend && npm run dev`（`node --watch src/index.js`），端口 8080，默认配置即可跑（无 `.env`，`dotenv` 走默认值：PORT 8080 / CORS `*` / SMS console）。SQLite 库在 `backend/data/duanxian.db`。
