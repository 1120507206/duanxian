# 2026-11-18

## ICP 备案号「看不到」排查 + 补齐应用内页面

- 现象：用户反馈首页底部看不到 `粤ICP备2026167467号`。
- 排查结论：**代码和提交都没问题**，Nov 2 那次只加在了营销页 `views/Landing.vue`（站点根路径 `/`）。
  - `/` 实测可见：元素 `.footer-icp` 存在，文档高 3645px，备案号在 3645 附近，正常渲染
  - `/home`、`/ztlive`、`/about`（走 `components/layout/AppLayout.vue` 的应用内页）**全部没有**
  - 用户登录后落在 `/home`（页面标题就是「首页 - 短线侠」），所以「首页看不到」成立
- 修复：在 `AppLayout.vue` 的 `.main-column` 里、`<main class="main-content">` 之后加常驻页脚 `.app-footer`
  - 固定 28px 高、`flex-shrink:0`、不参与 flex 增长，**不随内容滚动**（如果跟在内容末尾，满屏表格的页面会把它藏到滚动区底部）
  - 样式走 token：`--color-bg-card` 底 + `--color-border` 上边线 + `--color-text-muted` 字，hover 变 `--color-rise`
  - 链接到 `https://beian.miit.gov.cn/`
- 验证：Playwright 实测 `/home`、`/ztlive` 的 `.app-footer` 均 `bottom=900`（贴视口底）、`height=28`、文字正确；`npm run build` 后 `dist/assets/AppLayout-*.js` 与 `Landing-*.js` 都含备案号。
- 教训：这类「全站页脚」类需求，先确认用户说的「首页」是 `/`（营销落地页）还是 `/home`（登录后首页）—— 本项目两者是两套脚手架，落地页自带 footer，应用页走 AppLayout 无 footer。
- 未做：`ztlive.html` 独立页（通达信面板嵌入）仍未放备案号，面板空间小，待确认是否需要。
