# 短线侠 ·「涨停播报」商业化启动与推广获客方案

> 编制日期：2026-10-16
> 分析对象：`D:/code/duanxian`（短线侠 / duanxianxia）
> 结论先行：**这件事有商业化潜力，但当前形态不具备商业化「能力」。**
> 建议：先花 2 周补齐「能收钱 + 能算数」的地基，再动手推广。先推广 = 烧流量不留痕。

---

## 一、项目现状盘点（基于实际代码与文档，不是设想）

### 1.1 已经具备的资产

| 维度 | 现状 | 商业化意义 |
|---|---|---|
| 产品收敛 | 全站收敛为「只推涨停播报」，侧边栏只留 `/ztlive`，其余功能入口隐藏但路由保留 | 单点突破的形态已经对了，是好事 |
| 双入口 | 站点页 `/ztlive` + 独立页 `/ztlive.html`（独立打包、无侧边栏） | 独立页是**分发的核心资产**，专供通达信嵌入 |
| 语音播报 | 浏览器 TTS（优先中文音色）+ 旧站 mp3 音源兜底；开关/试听/语速/音量/播报范围；只播「打开后新增」的涨停与炸板 | **唯一能一句话讲清的差异化钩子**，市场稀缺 |
| 数据字段 | 涨停/炸板、连板数、封单额、成交额、首/末封板时间、换手率、流通市值、板块、**涨停原因**、可转债 | 「涨停原因」是多数 App 缺失的关键信息（只给榜不给逻辑） |
| 数据链路 | 上游约 3 秒重写快照 → 后端 1.5s 缓存窗口 + 单飞 + 过期重抓 → 端到端 ≤3~4s | 「秒级」，**但不是「瞬时」**（旧站有 WebSocket 秒级推送，我们目前没有） |
| 降级能力 | 上游故障时返回带时间戳的旧快照而非错误页；页面 30 秒无更新提示 | 稳定性设计已超出个人项目水准 |
| 部署链路 | PM2 + Nginx 模板（缓存头/压缩/安全头）+ HTTPS + SQLite 备份与恢复脚本 + 上线自检脚本 + GitHub Actions | 交付成熟度**足够支撑 MVP 上线** |
| 合规姿态 | `/about` 数据来源与风险说明页、首访风险提示、`/status` 状态中心 | 有合规意识，方向正确 |
| 营销页 | `/` 落地页：6 张功能卡、三步使用、定价区、页脚免责声明 | 骨架有了，但有 3 处硬伤（见 1.3） |

### 1.2 商业化的硬缺口（推广前必须补）

| # | 缺口 | 现状 | 后果 |
|---|---|---|---|
| 1 | **没有用户体系** | 无注册登录、无 JWT；自选股是「全局 SQLite + localStorage」混合 | 无法识别用户、**无法做付费墙**、无法算留存 |
| 2 | **没有支付闭环** | 定价区的「立即体验」按钮只是跳 `/ztlive`；无订单、无激活 | 有价格、无收入，等于摆设 |
| 3 | **没有任何埋点** | 全仓无统计 SDK、无访问日志分析 | 推广出去也不知道哪来的人、留了几个 |
| 4 | **无法归因** | 「复制链接」只复制 `origin/ztlive.html`，不带任何来源标识 | 多渠道一起推，谁也说不清哪个有效 |
| 5 | **定价模型自相矛盾** | 月付 ¥19.9、年付 ¥299，却标注「节省 25%」——19.9×12=¥238.8，**年付比按月买贵 25%** | 懂行用户一眼看穿，直接损害专业感 |
| 6 | **落地页数据造假** | Hero 区硬编码「10000+ 活跃用户 / 5000+ 日均追踪 / 99% 数据准确率」 | 《广告法》虚假宣传风险 + 一旦被拆穿信任归零 |
| 7 | **数据源单点** | 依赖第三方公开快照（`ds.duanxianxia.com`）与 mp3 音源域名，商用授权未确认 | 接口变脸即断供，付费用户会要求退款 |
| 8 | **无监控告警** | `LAUNCH.md` 自己承认「还没有集中监控」 | 付费用户遇到断播，你比他还晚知道 |
| 9 | **架构上限低** | 单机 SQLite + 内存缓存 | 几百并发即见顶，付费规模化前必须先升级 |
| 10 | **备案未完成** | ICP 备案、面向公众金融数据服务的合规评估待办 | 见第七节，这是硬约束 |

### 1.3 落地页三处必须立刻改的硬伤

1. **定价方向错了**：年付应显著低于 12×月付，现方案反了。建议改为「月付 ¥39 / 季付 ¥88 / 年付 ¥268」。
2. **免费与收费自相矛盾**：Hero 徽标写「推广期免费体验」，定价区又写「推广期限时免费 / 推广期间所有功能免费使用」，同时排出两档价格。**同一页不能既免费又收费**——建议明确为「免费版可用，语音等增值功能付费」。
3. **数字必须真实**：把统计数字换成真实埋点数据，或者干脆撤掉。真实的小数字（如「今日播报 XXX 条」）比虚假的大数字更有说服力。

## 二、核心价值与差异化定位

### 2.1 一句话价值主张

> **把「盯涨停」这件事，变成不用盯。**
> 挂进你正在用的通达信面板，有新涨停 / 炸板就出声，该干嘛干嘛。

### 2.2 价值分三层

| 层级 | 内容 | 竞品是否普遍具备 | 商业化角色 |
|---|---|---|---|
| 信息层 | 全市场涨停/炸板池 + 涨停原因 + 封单 + 连板高度 + 板块分布 | 具备（同花顺、东财、舞阳） | 入场券，**不是卖点** |
| **注意力层** | **语音增量播报**：只播打开页面后新增的涨停/炸板，不念历史 | **普遍缺失** | **付费核心**，也是唯一能一句话讲清的东西 |
| 工作流层 | 嵌入通达信/同花顺「通用浏览器」，不改变用户已有习惯，零迁移成本 | 少数免费单文件插件具备 | **分发护城河 + 转化加速器** |

### 2.3 竞品与定价对标（关键参照）

| 竞品 | 形态 | 定价 | 我们的相对位置 |
|---|---|---|---|
| 同花顺 / 东方财富 | 综合终端，涨停雷达、语音查询 | 基础免费，Level-2 付费 | 数据全但噪音大、涨停原因浅、无法嵌第三方软件 |
| 舞阳量化 | 短线量化复盘 | **约 ¥600 / 月** | 我们便宜一个数量级；它是「复盘重工具」，我们是「盘中轻工具」 |
| 小刺客涨停预警 | L2 涨停预警 + 联动交易 | **¥3580 – 5880 / 年** | 价格带证明：打板族群愿付能力**极强** |
| 知识星球财经社群 | 内容 + 社群 | **¥299 – 1499 / 年**（头部博主 1.7 万会员 × 1499 ≈ 年入 2000 万+） | 说明「信息焦虑」付费天花板很高，但我们**坚决不碰内容荐股**（见第七节） |
| 通达信 HTML 插件（免费单文件） | 本地 HTML，打赏/私信领取 | 免费 / 打赏 | 竞品多、无维护、无语音、无服务端 → 这是我们能收钱的原因：「有服务」 |

**定价锚点结论**：不要跟 ¥600/月比，也不要 ¥19.9/月自贬。
- 月付 ¥39 / 季付 ¥88 / 年付 ¥268 —— 相对竞品仍便宜一个量级，但足够覆盖服务器与运维，且有毛利。
- **语音播报就是付费墙的位置**：免费看表，付费才出声。

### 2.4 目标用户分层

| 分层 | 画像 | 核心痛点 | 付费意愿 | 主渠道 |
|---|---|---|---|---|
| **A 核心** | 职业/半职业打板客、接力选手 | 封板瞬间错过 | 强，¥300–1500/年 | 淘股吧、通达信插件圈、付费社群 |
| **B 主力** | 兼职短线的上班族 | **无法盯盘**（语音是刚需中的刚需） | 中，¥100–300/年 | 公众号、抖音/视频号、知乎 |
| C 长尾 | 泛股民、复盘学习者 | 想知道「为什么涨停」 | 弱 | 免费为用户，负责拉新与口碑 |
| **D 渠道商** | 通达信插件博主、公众号主、社群主 | 需要内容/工具维系粉丝 | — | **分销杠杆，零预算起量关键** |

> 关键洞察：**B 层是最大基数，且语音功能对 B 层是刚需**——上班族不可能全天盯屏，但有声提醒可以。「离屏可用」是我们真正的市场缝隙。所有定位与文案都应围绕 B + A，而不是泛股民。

## 三、商业化潜力判断

### 结论

**具备商业化潜力，但当前不具备商业化能力。** 潜力打 7 分（满分 10），当前就绪度打 3 分。

### 看好理由

1. **需求与付费已被市场验证**：同赛道价格带从 ¥98/月 到 ¥5880/年 都有人买，知识星球财经社群 1499/年也能卖到 1.7 万人。
2. **产品形态落在合规安全的一侧**：我们是「行情数据展示工具」，不是「荐股服务」。这个差别是整个项目能不能做大的生死线，而我们**天生在安全侧**——这是最大的隐形优势。
3. **有一个真正稀缺的功能**：语音增量播报 + 可嵌入交易软件，这两点组合在市面上几乎看不到。
4. **技术底子够用**：部署、降级、备份、自检都齐，一个人也能运维。

### 看空理由（决定天花板）

1. **可复制性极高**：前端单文件 HTML 插件遍地都是，护城河只有「数据稳定性 + 语音体验 + 渠道关系」三条软性壁垒。
2. **数据不掌握在自己手里**：单点第三方快照，商用授权未明——这是资本层面最致命的一条。
3. **当前无收入闭环、无用户体系、无数据**：三无状态下谈增长是空转。
4. **天花板现实区间**：单一工具做到年营收几百万是务实目标。做「工具 + 社群 + 课程」复合能上千万，但**合规风险陡增，不建议**。

### 推荐商业模式

| 类型 | 方案 | 理由 |
|---|---|---|
| **主：Freemium 订阅** | 免费版：桌面页面看表格（含涨停原因、板块）。付费版：语音播报、板块订阅过滤、历史回溯、免登录多设备 | 语音「感知价值最高、边际成本最低」，是最佳付费墙位置 |
| **辅：渠道分成** | 给通达信插件博主 / 公众号主 **30–40% 首年分成**，用现成渠道换起量 | 零预算下最快的获客方式，且对方有现成精准流量 |

**明确不做**：荐股、带单、付费群卖「明日标的」、收益承诺、代客理财。理由见第七节。

## 四、从零开始的推广获客行动清单

### 阶段 0：地基期（第 0–14 天）— 优先级 ★★★★★

> **原则：先能收钱、能算数，再谈拉人。** 这一阶段不做任何对外推广。

| # | 动作 | 验收标准 |
|---|---|---|
| 0.1 | **修定价**：改为月 ¥39 / 季 ¥88 / 年 ¥268；删掉「节省 25%」的矛盾表述 | 落地页定价区逻辑自洽 |
| 0.2 | **删假数据**：移除 10000+ 用户 / 99% 准确率；或替换为真实数据（如「今日播报 87 条涨停、12 条炸板」） | 无任何无法举证的表述 |
| 0.3 | **最小用户体系**：不做注册。前端生成匿名 `deviceId`（localStorage），服务端仅存 `deviceId + 到期时间 + 来源码` | 能识别设备、能判断付费状态、不碰个人信息 |
| 0.4 | **渠道码**：`/ztlive.html?c=xxx` 透传来源，落地即上报并持久化 | 每个渠道的访问/付费可归因 |
| 0.5 | **埋点**：接入轻量统计（Umami 自建或 GA4+百度统计）。核心事件：页面打开、语音开启、嵌入成功、复制链接、付费 | 事件可在看板查询 |
| 0.6 | **支付闭环（先人工后自动）**：第一版用知识星球 / 爱发电 / 微信收款码收款 → 人工发激活码；跑通 10 单后再接自动 | 能在 10 分钟内完成一笔真实收款并发码 |
| 0.7 | **语音体验升级到「能当闹钟」**：首访引导开启语音（而非默认关闭）、播报失败降级提示、后台/锁屏可用性测试 | 手机端后台播放可用 |
| 0.8 | **数据源合规确认**：向上游确认商用授权；同时准备第二数据源与本地快照兜底 | 有书面结论或替代方案 |
| 0.9 | **监控告警**：上游抓取失败、接口 P95 延迟超阈值 → 推送到你自己的微信/邮件 | 断播 5 分钟内收到告警 |

**阶段目标**：具备「可收钱、可归因、可告警」的最小商业化闭环。**预期指标：0 收入，但 100% 具备开闸条件。**

### 阶段 1：冷启动期（第 15–45 天）— 只打 3 个精准渠道，不做全平台铺量

#### 渠道 1（最高优先级）：通达信插件生态

**为什么**：这里的用户**已经会「挂插件」**（版面 → 新建定制版面 → 通用浏览器 → 填网址），无需教育；且现有免费插件普遍无维护、无语音、无服务端——我们的「有服务」是降维打击。

**做什么**：
- 把「嵌入教程」做成**可复制的传播资产**：一图流教程（截图标注每一步 + 可直接粘贴的网址）+ 90 秒视频。
- 定向投放到插件聚集地：股指标网类论坛、夜雨聆风类工具博客、70822/分析家公式网类下载站、B站「通达信插件」关键词视频。
- 每个渠道用独立渠道码（`?c=gzb`、`?c=yylf`、`?c=bili`），验证哪条最有效。

**预期**：此渠道贡献 40–50% 的有效嵌入用户。

#### 渠道 2：淘股吧 + 东方财富股吧

**为什么**：垂直、精准、全是短线客，无需教育成本。

**做什么**：
- 只发三类内容：**每日涨停复盘数据**（我们本来就有）、**板块梯队梳理**、**工具使用教程**。
- 内容模板：`【10/16 涨停复盘】87 家涨停，封板率 78%，最高 5 板（XXX 板块 4 家）……我用工具自动播报，需要的自己取。`
- **绝对不做个股买卖建议**。淘股吧封号率高，主号只做内容、不打硬广，引流靠简介与置顶。

**预期**：贡献 20–30% 的访问量，用户精准度最高。

#### 渠道 3：微信公众号（复用存量资产）

**为什么**：如果你此前运营过短线侠旧站（`www.duanxianxia.com` 目前在线），**公众号粉丝是现成的第一批种子用户**，这比从零冷启动快得多。

**做什么**：
- 公众号定名如「短线侠涨停播报」，菜单直接挂 `/ztlive.html`。
- 建立内容节律：**每个交易日 9:25 前发一条「昨日涨停板块分布」**，形成打开习惯。
- 把独立页链接当作「工具交付物」而非「广告」——工具类链接的分享率远高于广告。

**预期**：贡献 20–30% 的访问量，留存质量最好。

#### 阶段 1 内容策略基调（红线）

| 要做的内容 | 绝不碰的内容 |
|---|---|
| 市场事实呈现（涨停家数、封板率、板块分布） | 个股买卖建议、「可关注」「可埋伏」 |
| 工具教程、使用方法、效率技巧 | 「明日涨停预测」、点位指导 |
| 复盘方法论、数据口径科普 | 收益截图、跟买号召、承诺收益 |
| 产品更新日志、稳定性报告 | 任何形式的「带单」「代客」 |

| 指标 | 目标 |
|---|---|
| 累计独立访客 UV | 3,000 – 8,000 |
| 通达信嵌入成功数 | ≥ 150 |

### 阶段 2：留存与口碑期（第 46–90 天）— 比拉新更重要

> 工具类产品的死亡原因几乎都是留存，不是获客。

| # | 动作 | 说明 |
|---|---|---|
| 2.1 | **建用户群**（微信/QQ） | 群定位**只能是**「产品反馈与使用答疑」。群名不得含「股票池/牛股/涨停」等敏感词 |
| 2.2 | **建立使用节律** | 每个交易日盘前推「昨日板块分布」（事实陈述，非推荐），培养固定打开习惯 |
| 2.3 | **北极星看板** | 只盯一个数：**「语音开启且停留 > 20 分钟的周活跃设备数」** |
| 2.4 | **邀请机制** | 老用户分享带渠道码链接，被邀请人首次付费 → 双方各得 15 天 |
| 2.5 | **渠道分销** | 谈 3–5 个插件博主/公众号主，给 30–40% 首年分成，做「零预算放大器」 |
| 2.6 | **留存归因分析** | 重点看：**开启语音的用户 vs 未开启用户的 7 日留存差**——这个差值直接验证付费墙假设 |

### 阶段 3：规模化与护城河期（第 90 天以后）

### 7.1 合规风险（最高优先级，直接决定生死）

**核心判断标准**：我们是**行情数据展示工具**，不是**证券投资咨询**。这条线必须时刻守住。

**绝对禁止清单**：
- ❌ 任何形式的个股买卖建议、点位指导、仓位建议
- ❌ 付费群 / 直播间里的「带单」「抄作业」「明日标的」
- ❌ 收益承诺、晒盈利截图、暗示「跟买能赚」
- ❌ 代客理财、收益分成、诱导开户入金
- ❌ 宣传语中出现「预测涨停」「稳赚」「必涨」「翻倍」

**监管依据与判例（务必读过）**：
- 《证券法》第 120 条、第 160 条 + 《证券、期货投资咨询管理暂行办法》第 3 条：**只有持牌证券公司及证券投资咨询机构可从事证券投资咨询业务**。
- **2025 年 10 月，北京市朝阳区人民法院判例**：无资质网络博主通过付费群「精准荐股」，以**非法经营罪**判处有期徒刑 2 年 6 个月，并处罚金 **1500 万元**。
- **2025 年**：雪球大 V 金某因「抢帽子操纵」被浙江证监局**罚没超 8300 万元**，并处 3 年市场禁入。
- **2025 年 12 月**：中央网信办发布规范网络名人账号行为管理通知，将**无资质擅自从事荐股投资纳入负面清单**。
- 法院判例进一步明确：以「培训」「分析」「投教」包装的有偿荐股，**合同自始无效、费用全额返还**，情节严重构成非法经营罪。

**对推广的直接约束**：所有公众号文章、短视频脚本、群公告、落地页文案，**上线前逐条对照上面两张清单过一遍**。

**落地页具体待改项**：

### 7.2 数据源风险

- 单点依赖第三方公开快照（`ds.duanxianxia.com`）与音源域名（`bm.duanxianxia.com`），**商用授权状态必须尽快书面确认**。
- 接口可能随时变更、限流、下线；`LAUNCH.md` 已提示需服务器端实测。
- 缓解：双源 + 自建抓取 + 本地快照兜底（现有降级机制已具备基础）。

### 7.3 竞争风险

- 产品可复制性极高（单文件 HTML 插件遍地都是），**必须靠「数据稳定性 + 语音体验 + 渠道关系」这三条软壁垒生存**。
- 若竞品跟进语音，我们的先发优势会迅速消失 → **所以速度比完美重要，前 45 天必须跑起来**。

### 7.4 平台与交付风险

- 抖音/公众号对「荐股」类内容零容忍，误伤是常态 → 必须多渠道备份，不做单平台依赖。
- 单机 SQLite 架构在几百并发即见顶 → **付费用户破 300 前必须完成架构升级**。
- 交易时段是流量尖峰，也是故障最致命的时段（盘中断播 = 直接退款）。
