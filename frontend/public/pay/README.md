# 收款码图片放这里

收银台会按下面的文件名加载收款码，缺失时页面会显示「收款码还没配置」而不是裂图。

```
public/pay/wx.png      微信个人收款码
public/pay/alipay.png  支付宝个人收款码
```

## 怎么拿到

- **微信**：微信 → 我 → 服务（支付）→ 收付款 → 二维码收款 → 保存收款码
- **支付宝**：支付宝 → 收钱 → 保存收款码图片

建议用 `.png`，尺寸 400×400 以上，白底、只留二维码主体（微信默认那张带头像的也可以用）。
二维码周围留一点白边，扫成功率更高。

## 两件必须知道的事

1. **不要把这张图提交到公开仓库的敏感位置** —— 收款码本身不涉及资金安全（别人只能给你付钱），
   但它会出现在构建产物里，等于公开。确认你的部署范围之后再用。
2. **个人收款码没有支付回调**，所以用户点「我已付款」之后必须你人工核对账单再核销：

```bash
cd backend
npm run member orders                      # 看有哪些待核销
npm run member approve --order DX2026...   # 确认收到钱了，才执行这条
```

## 换图床

不想把图片放进代码仓库，可以在 `backend/.env` 里改成任意 URL：

```
PAY_WX_QR_URL=https://你的图床/wx.png
PAY_ALIPAY_QR_URL=https://你的图床/alipay.png
```
